# 现行流程怎么记

每页回答一项操作该从哪里开始。用户首次选择收录后，后续接手者可依据新证据维护同一页。项目已有正式手册时，直接链接到对应章节，保留足以选择正确流程的条件。

```markdown
# <操作名称>

适用范围：<环境、版本、角色或平台>
查找线索：<任务叫法或别名>

## 现行做法

<本范围内采用的流程、正式入口，以及判断操作完成的方式。>
生效依据：<正式决定、手册章节或已生效配置，日期已知时写明。>

## 待核实

<有分歧的具体步骤、新旧说法各自的依据，以及还要确认什么。>

## 已替代

- <日期>：<旧做法> → <现行做法>。<替换原因、影响范围及依据。>

## 依据

- [名称](相对该条目路径) <!-- sha256:64位小写摘要 -->
```

「待核实」和「已替代」按需填写。适用于不同环境的做法可以同时现行，分别写明各自范围。依据里的摘要取核对时本地来源整个文件的 SHA-256 值，链接可以指向具体章节。
